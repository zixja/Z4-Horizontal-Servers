# Horizontal Server List for Endcord

A simple custom theme for **Endcord** that moves your Discord server list from the left side of the client to a clean horizontal bar across the top.

Designed to keep the Discord layout familiar while giving Endcord a cleaner and more modern appearance.

## Features

- Horizontal server list
- Server folders support
- Clean top-bar layout
- Smooth server icon interactions
- Works with Endcord custom themes
- Easy to customize
- Lightweight CSS
- Keeps the normal channel and chat layout intact

## Installation

1. Download the theme CSS file.
2. Open **Endcord**.
3. Go to your custom themes/settings.
4. Add the theme file.
5. Enable the theme.
6. Reload Endcord if needed.

## Customization

You can edit the CSS to change things such as:

- Server icon size
- Server spacing
- Top bar height
- Background colors
- Hover effects
- Selected server indicators
- Folder appearance

## Compatibility

Made specifically for **Endcord** and the current Discord client layout.

Discord updates may occasionally change internal class names and require small theme updates.

## Issues

If you run into a bug, especially with server folders or layout changes, open an issue and include:
